# neulicht-resources
# 合同会社ノイリヒト

**ITで新しい光を。**

合同会社ノイリヒトは、AI・機械学習を中心とした技術の活用と、
AI・ITに関する教育・技術コンテンツの制作・発信に取り組んでいます。

生成AI、機械学習、ディープラーニング、AIエージェントなどの技術について、
「知る」だけでなく、実際に「学ぶ・使う・つくる」ことにつながる情報を届けることを目指しています。

YouTube「ITエンジニア ノイ」を中心に、AI・IT分野の学習コンテンツや技術情報を公開しています。

---

## 📚 このリポジトリについて

`neulicht-resources` は、合同会社ノイリヒトが作成した
**技術資料・講義資料・学習資料・サンプルコードなどを公開するためのリポジトリ**です。

AIやITについて学ぶ方、技術を実際に活用したい方に役立つ資料を順次公開していきます。

### 主なテーマ

- 生成AI
- 機械学習・ディープラーニング
- LLM
- AIエージェント
- AIリテラシー
- G検定などのAI関連資格
- Python・データ分析
- AI技術の調査・検証
- AIのビジネス活用
